# matchbox-ai

The Matchbox CLI provides the `matchbox-ai` command, task scaffolding, and browser workbench for existing applications. Install it as a development dependency alongside `@matchbox-ai/train` and `@matchbox-ai/core`. Authored pipelines continue to import primitives from `@matchbox-ai/train`.

Read [the bundled documentation](docs/cli.md) for commands and setup. The CLI uses the public training APIs; native TensorFlow and model packaging remain in the training package.
